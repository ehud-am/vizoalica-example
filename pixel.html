How it works

  • Off by default and enabled per website. Each image load is one page view under the path you choose.
  • An image request carries no origin, so anyone who knows the website key could forge views: use a separate website for READMEs.
  • GitHub and npm proxy images, so counts there are rough and unique visitors cannot be told apart.
  • The path must start with /, be at most 512 characters and have no ? or #.

Payload

One request, no script, no storage
