How it works

  • A rage click is 3 or more mouse or touch clicks on one control within 1 second.
  • At most one burst per control every 5 seconds, and 20 a minute per page load.
  • Keyboard activation never counts (holding Enter repeats clicks without frustration).
  • The burst is an extra action event flagged rage: true, sent in its own request, so a backend that does not know it rejects only the burst.
  • Stored: a count per minute, page and control. No visitor, session or position, so the report cannot say how many different people raged.

Read a burst as a prompt to look, not a verdict: a stepper button pressed repeatedly looks the same as frustration.

Payload

{
  "page": "/settings",
  "name": "Save changes",
  "kind": "button",
  "rage": true
}
