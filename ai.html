Ask an AI assistant

A local, read-only MCP server lets Claude, Codex or Cursor answer questions from your own analytics.

Vizoalica on GitHub

Example

You: Which campaign brought the most visitors last week, and where are people rage clicking?

Assistant (illustrative answer): In prod, spring-sale (newsletter / email) led with the most visitors. The Save changes button on /settings had the most rage-click bursts.

Tools the assistant can call

ToolReads
get_environment_statusRole and scope, Worker and database versions, health
get_website_statusCollection and configuration status, excluded-address counts, install check
get_traffic_overviewPage views, visitors, trend, top pages, referrers, countries, devices
get_actionsClicks on buttons and links, by page
get_custom_eventsCustom events: count, visitors, trend, pages, property values
get_campaignsWhich tagged links brought visitors
get_rage_clicksControls clicked repeatedly in quick succession
get_goalsConversions of a website’s goals

Privacy and safety

  • The MCP server runs on your computer and works on every environment you have.
  • It names the environment in every answer.
  • It is read-only and never hands a secret to the AI client.
