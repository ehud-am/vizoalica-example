How data flows

  1. A page loads one script tag, served by your own Cloudflare Worker.
  2. The SDK filters URLs, referrers and properties in the browser, then sends non-blocking batches.
  3. The Worker validates again, counts unique visitors with a daily-rotating hash, and writes raw batches to R2 and aggregates to D1.
  4. You read the results in the local console, or ask an AI assistant through the local MCP server.

The one tag this site uses

Every page of this demo has the same generic, configuration-free tag. The values are fetched at runtime from /vizoalica/config.json (the dynamic CI/CD path), so no endpoint or key is committed to this repository.
