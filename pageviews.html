Page views

A page view is sent on load and again whenever a visitor reaches a different page key, with no cookies.

Payload

For a page at https://example.com/pricing?token=secret&plan=pro the SDK sends structured, minimised data. The query value never leaves the browser.

Equivalent structured data
{
  "url_origin": "https://example.com",
  "url_path": "/pricing",
  "url_query_redacted": true
}

How it works

  • A page is named by its page key: the path, plus the route after # when it starts with /.
  • A view is sent on load and when pushState, replaceState, back/forward or a fragment change reaches a different key.
  • Anchors, tokens and other fragments are ignored, so sign-in data in an address is never recorded.
  • If consent is explicitly analytics-denied, in-page navigation views are not sent.
