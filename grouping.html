Rules

A segment that is…BecomesExample
digits only:id8841
a UUID:id3f2b8c1e-…
hexadecimal, 16+ characters:id5f2b8c1e5d4a4a37
a ULID:id01ARZ3NDEKTSV4RRFFQ69G5FAV
a 20+ char token with upper, lower and digit:idV1StGXR8_Z5jdHi6B-myT
contains @:idjane@example.com
words, slugs, versions, file nameskeptmy-first-post
year, month, optional daykept/blog/2026/09/launch

The browser groups first and the backend applies the same rule again, so older SDK files and other clients are covered too. Readable slugs that identify a record (/products/blue-widget) cannot be recognised and stay separate; the long tail collapses into “Other” in the console.
