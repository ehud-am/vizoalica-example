How it works

  • The name: lowercase letters, digits, underscores; starts with a letter; 2 to 64 characters.
  • Properties are optional: up to 25 with text, number, boolean or null values. Sensitive-looking names (email, password, token, …) are rejected.
  • The page is added automatically, as a page key (/orders/:id).
  • Text and boolean values are grouped (redacted, cut to 64 characters, up to 10 properties per event). Numbers are collected but not grouped.
  • Report: console Analytics → Events, or get_custom_events in your assistant.

Payload

{
  "event": "signup",
  "page": "/pricing",
  "properties": { "plan": "pro", "annual": true }
}
