Browser switch

Open any page of your site once with ?vizoalica_ignore=1 and that browser sends nothing. This stores one value in your own browser, and is the only thing the SDK ever writes. Try it on this demo:

How it works

Excluded addressesBrowser switch
Good forOffices or homes with a fixed addressChanging connections, phones
Set up inConsole, website → EditOpening a link once
Counted for transparencyYes, per dayNo (nothing is sent)
  • Excluded visits are dropped on arrival and never stored; only a per-day count is kept, for 32 days.
  • Not retroactive. Shared addresses exclude everyone behind them. Up to 25 IPv4/IPv6 addresses or ranges.
